# Macresta

A premium digital house for brands that refuse to blend in.

## Pages

- **index.html** — Homepage with cinematic hero, work grid, social proof, and CTA
- **services.html** — How We Work step-by-step process page
- **about.html** — Team, values, and company story
- **effects.js** — Custom cursor, 3D effects, particles, and interactions

## Tech

Pure HTML/CSS/JS. No frameworks. Designed for performance.

- Cinzel + Cormorant Garamond + Manrope typography
- Custom gold cursor with ring + ripple effects
- 3D tilt, parallax, and magnetic interactions
- Golden dust particle system
- Scroll-triggered reveal animations
- Grain texture + vignette atmospheric layers
